# 1주차 WIL

## 배운 것

웹은 HTML, CSS, JavaScript 세 가지로 만들어진다.

- HTML: 무엇이 있는지
- CSS: 어떻게 보일지
- JavaScript: 어떻게 동작할지

HTML이랑 CSS만 있으면 화면은 나오지만 버튼을 눌러도 아무 일도 일어나지 않는다. 그 부분을 JavaScript가 담당한다.

### DOM

브라우저가 HTML을 읽어서 트리 구조로 만들어둔 것이 DOM이고, JavaScript는 이걸 통해서 요소를 찾고 바꾼다. 그래서 `document.querySelector("h1")`처럼 document부터 시작하는 것이었다.

```js
document.querySelector("h1").textContent = "안녕하세요!";
```

개발자 도구(F12) 콘솔에 이 코드를 입력하니까 실제로 제목이 바뀌어서 신기했다. 하지만 새로고침하면 원래대로 돌아간다. 파일을 고친 게 아니라 지금 화면만 바꾼 것이기 때문이다.

### Event

실제 사용자는 콘솔에 코드를 치지 않고 클릭하고, 입력하고, 스크롤한다. 이런 행동을 코드로 받을 수 있게 해주는 것이 이벤트다.

사람의 행동 → Event → JavaScript → 화면 변화

하트를 누르면 10이 11이 되는 예시를 보고 바로 이해가 됐다.

## 느낀 점

생각보다 간단한 코드로 화면이 바뀌어서 재밌었다.
